# 星詠堂（HOSHIYOMI-DO）— 占いサイト

生年月日と「いまの気持ち」から鑑定文を自動生成する、占いサイトのフロントエンド一式です。
ビルド不要。`fortune/index.html` をブラウザで開けば動きます。

```
fortune/
├── index.html              マークアップ（1ページ完結）
└── assets/
    ├── css/style.css       デザインシステム（トークン／レイアウト／装飾）
    └── js/
        ├── data.js         鑑定データ（星座・数秘・五行・干支・月相・タロット・感情トーン）
        ├── engine.js       算出エンジン（決定論的乱数・暦・数理・チャート生成）
        ├── writer.js       文章の組成（無料鑑定／詳細鑑定の各章）
        └── app.js          UI（星空・フォーム・鑑定書描画・図表・課金導線・継続来訪）
```

## 生成の仕組み

1. **入力** — 名前（任意）／生年月日／出生時刻（任意）／相談カテゴリ／**いまの気持ち**／自由記述（任意）
2. **鍵の導出** — 入力を連結して FNV-1a でハッシュ化し、mulberry32 の種にします。
   同じ入力からは必ず同じ乱数列が出るため、**何度引いても結果は変わりません**（鑑定番号 `HY-xxxxx-XXn` で再現可能）。
3. **算出** — 以下はすべて計算で求めています（`engine.js`）。
   | 項目 | 方法 |
   |---|---|
   | 太陽宮 | 月日から十二宮を判定（トロピカル方式・境界日テーブル） |
   | 運命数 / 個人年 / 個人月 | ピタゴラス式数秘（11・22・33 はマスターナンバーとして保持） |
   | 干支・十干 | 生年の剰余から決定 |
   | 五行バランス | 太陽宮・十干・十二支・生月・運命数を加重して正規化 |
   | 月相 | 2000-01-06 18:14 UTC の朔を基準に朔望月 29.530588853 日で計算 |
   | バイオリズム | 経過日数 n に対し sin(2πn/23)、sin(2πn/28)、sin(2πn/33) |
   | 十二ヶ月曲線・転機の日 | バイオリズム＋個人月数を合成し、最良月の中で感情周期が最大の日を特定 |
   | タロット | 種＋当月から決定論的にシャッフル（月が変わると更新） |
4. **文章の組成** — `writer.js` が、算出結果と「いまの気持ち」のトーンを掛け合わせて各章を編みます。
   気持ち（つらい／迷っている／前向き／立ち止まっている／決めたい）によって、**書き出し・接続・結び・助言の強さ**が変わります。

## 内容量（実測）

| | 章数 | 文字数（実測・平均） |
|---|---|---|
| 無料鑑定 | 3 | 約 800 字 |
| 光の章 ¥1,980 | +15 | 約 6,500 字 |
| 深淵の章 ¥4,980 | +21 | 約 9,300 字 |
| 宿命の書 ¥12,800/年 | +22 | 約 9,500 字＋鑑定士の個別便り＋毎月更新 |

サイト上の表記はこの実測値に合わせてあります。数字を変えるときは
`assets/js/app.js` の `TIERS`、`index.html` の `.plan-vol`、FAQ の該当箇所をあわせて更新してください。

## 継続利用の仕組み

- **今日の運勢** — 端末に保存したプロフィールと当日の日付から毎日算出（登録不要・無料）
- **参詣日数** — 連続来訪をカウントし、3日／7日／14日で特典コードを発行（`localStorage`）
- **鑑定履歴** — 直近12件の鑑定書を端末内に保存し、いつでも再現可能
- **次のご来館** — 次の満月・新月・転機の日を鑑定書の末尾に提示

## デモとして未実装の箇所

本サイトは**デモンストレーション**です。実装する場合は以下を差し替えてください。

- **決済** — `app.js` の `openPay()` / `#payGo` がモーダルを出すだけです。Stripe Checkout 等の
  セッション生成に差し替え、`UNLOCKED` の設定はサーバー側の購入検証結果から行ってください。
  現状の `#demoUnlock` は削除対象です。
- **実績数値・お客様の声・鑑定士紹介** — すべてサンプルです（`index.html` の `data-count`、
  `app.js` の `VOICES`、鑑定士セクション）。実データに置き換えてください。
- **単品メニュー** — 価格表の単品アドオンは生成に対応していません。
- **特定商取引法に基づく表記／プライバシーポリシー／利用規約** — フッターのリンクは
  現在 FAQ を指しています。実ページを用意してください。

## 方針として守っていること

- 無料鑑定の入力はブラウザ内でのみ処理し、外部送信しません。
- 「必ず当たる」とは書かず、算出方法をすべて公開しています。
- 医療・法律・投資の助言ではない旨をフッターに明記しています。
- 毎日課金を促す設計にしていません。「今日の運勢」は無料のままです。

## 対応環境

モダンブラウザ（Chrome / Safari / Firefox / Edge）。`prefers-reduced-motion` に対応し、
アニメーションを抑制する設定では星の瞬き・カードのめくり・演出をすべて停止します。
印刷用スタイルを同梱しており、鑑定書はそのまま PDF として保存できます。
