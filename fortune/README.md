# 星詠堂（HOSHIYOMI-DO）— 占いポータル

生年月日・名前・引いた札から鑑定文を自動生成する占いサイトです。ビルド不要、`index.html` を開けば動きます。

```
index.html              HOME（1ページ完結）＋鑑定オーバーレイ
assets/
├── css/style.css       デザインシステム（紫紺×金襴、文字の強弱、装飾）
└── js/
    ├── data.js         鑑定データ＋メニュー定義（29種）
    ├── engine.js       算出（暦・数理・かな画数・札引き・相性）
    ├── writer.js       鑑定文の組成（感情の運びと課金ゲート）
    └── app.js          UI（星空・ジャンルタブ・鑑定オーバーレイ・図表）
```

## 導線

料金はHOMEに一切出しません。ジャンル → メニュー → 最小入力 → 鑑定開始、と読み進めた
**途中で課金ゲートが現れます**。無料で読める範囲は「あなたがどんな人か」まで、
その先の「いつ・何をすべきか」が有料です。

無料部分の最後は必ず言いさし（「それは——」）で終わり、続く有料章の冒頭2行が
フェードアウトしながら見えたところにゲートが乗ります。

## 感情の運び

鑑定文はすべてこの順で組まれています。

| 章 | ねらい | 例 |
|---|---|---|
| 壱 あなたという人 | **納得感** | 「人前では平気な顔をしていられる人ですね」といきなり言い当てる |
| 壱（後半） | **安心感** | 「それはあなたの落ち度ではありません」と受け止める |
| 弐 気がかりなこと | **危機感** | 「このまま続けると——」で切れる（ここでゲート） |
| 参 その答え | **解決** | 具体的な日付・行動・避けるべき相手 |
| 肆・伍 開運／結び | **安堵** | 護符と、責めない言葉で終える |

危機感は「時機を逃す」「同じ型を繰り返す」という形にとどめ、不幸や災いを煽る表現は使っていません。

## 4つの鑑定エンジン

| エンジン | 入力 | メニュー例 |
|---|---|---|
| `tarot` | **入力なし**（札を選ぶだけ・10秒） | 今日引くべき一枚／YES・NO／五枚展開 |
| `seimei` | **ひらがなの姓名だけ** | 名前が示す本質／名前で視る恋愛運／名前どうしの相性 |
| `natal` | **生年月日だけ** | 宿命／前世／転機の日／天職／金運／恋愛 |
| `compat` | **生年月日ふたつ** | ふたりの相性／あの人の本音／復縁の可能性 |

**「いまの気持ち」は訊きません。** 手軽さを優先しています。

## 算出（すべて計算）

- 太陽宮：月日から十二宮を判定
- 運命数・個人年月：ピタゴラス式（11・22・33は保持）
- 干支・十干・五行バランス：生年の剰余と加重から
- 月相：朔望月 29.530589 日
- バイオリズム：sin(2πn/23)、sin(2πn/28)、sin(2πn/33) → 十二ヶ月曲線と「転機の日」
- 姓名判断：**かな画数表**による五格（天格・人格・地格・外格・総格）と三才。
  濁点+2画・半濁点+1画。カタカナは自動でひらがなに寄せます
- 相性：五行の相生相剋＋星座の角度＋運命数の差から五軸を算出

入力をハッシュ化して mulberry32 の種にしているため、**同じ入力からは必ず同じ鑑定文**が出ます。

## 上にもどるボタン

ホーム画面のみ。右下に 38px の丸ボタン（↑のみ、ラベルなし）で、1画面分スクロールすると現れます。
鑑定オーバーレイを開いているあいだは自動で隠れます。鑑定結果側にはボタンを置いていません。

## 完全無料の鑑定

課金ゲートが出ない「全文無料」メニューを、4つのエンジンすべてに用意しています。

- 今日引くべき一枚（タロット）
- 今すぐ答えが欲しい YES / NO（タロット）
- 名前で視る恋愛運（姓名判断）
- この人と組んで大丈夫？（相性）
- 気の巡りと体質（生年月日）

`data.js` の `MENUS` で `free:true` を付けたものが対象です。カードには金緑色の「全文無料」バッジが付き、
読み終わりに全文無料である旨の帯が出ます。

## 意匠と文言の方針

配色・レイアウトは変えずに、密度だけ足しています。

- 全面に三角格子（麻の葉風）の地紋を薄く敷く
- 御品書カードは二重罫＋上辺の留め＋八卦の透かし
- 鑑定書とヒーローの札に落款（朱の角印「星詠」）
- 節と節のあいだに罫、見出しの下に飾り（❖ ✦ ❖）
- 帯・枠は内側にもう一本罫を重ねる

文言は、長文の鑑定本文以外はすべて短く詰めています。

| 場所 | 前 | 後 |
|---|---|---|
| メニュー名 | 今日引くべき一枚 | 今日の一枚 |
| | あなたの宿命 | 宿命 |
| | 転職・独立の適期 | 動く刻 |
| 章題 | あなたという人 / 気がかりなこと / その答え | 素性 / 兆し / 答え |
| ゲート | この続きに、答えがあります | ここから、核心。 |
| ゲート項目 | 時期・行動 | 刻・手 |
| ボタン | いますぐ無料で視てもらう | 無料で視る |
| ナビ | 鑑定メニュー / 鑑定士 / 体験談 | 御品書 / 視る者 / 声 |

## モバイル

小さい画面を基準に詰めています。ジャンルは横スクロールの帯、ボタンは最小48px、
主要ボタンは全幅、節の余白と鑑定書の余白を縮め、本文は 1rem・行間2.5に。

## 組版

- `word-break: auto-phrase` と `line-break: strict` で、日本語を文節単位で折り返します
- 見出しは `text-wrap: balance`、本文は `text-wrap: pretty` で行末を整えます
- 本文の行間は 2.6。強調語は `box-decoration-break: clone` で行またぎでも崩れません
